# Agent HQ

A live 3D office dashboard for AI agent teams — 8 teams, 31 agents, one Data Center.

Open `index.html` in any modern browser, or visit the deployed site. The 3D floor
(corridor, glass team offices, Director's cabin, Data Center server room) runs on
Three.js, loaded from a CDN. All activity on the floor is a live simulation:
agents walk in when work starts, paper planes carry handoffs between teams, and
anything waiting on the Director raises a hand.
